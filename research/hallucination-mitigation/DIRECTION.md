# 엔트로피 기반 할루시네이션 "탐지 → 생성 중 조치" 연구 방향

> 입력: Villani et al., *Entropy Distribution as a Fingerprint for Hallucinations in Generative Models* (CES), JPMorganChase, [arXiv:2605.28264](https://arxiv.org/abs/2605.28264) (2026)
> 사용자 조건: **국제 워크숍 · 1~2개월 · API/로컬 추론만(학습 불가) · 분석/벤치마크 기여 · 생성 중 개입**

## 1. 입력 논문 분석

CES는 토큰 엔트로피의 **분포 모양·꼬리**(평균만이 아니라)가 할루시네이션의 지문이라는 관찰을 가설검정으로 정식화한다. 보정 데이터로 기준 CDF를 만들고, 단일 포워드 패스의 엔트로피 시퀀스가 기준과 통계적으로 일치하는지 검정 (finite-sample 보장 포함). **탐지까지만 하고 조치는 하지 않는다.**

저자가 명시한 한계 (= 갭의 1차 소스):
1. 모델이 높은 확신으로 할루시네이션하면 원리상 탐지 불가 (dKS=0이면 어떤 검정도 무력)
2. 짧은 생성(m<10 토큰)에서 검정력 저하
3. 조건부 i.i.d. 가정 — **순차 구조 모델링은 명시적 future work**
4. logit 접근 필요 — 일부 API 제공자는 미지원
5. 실험이 greedy 디코딩 + 단답 QA에 한정 — **확률적 디코딩·장문 생성 확장은 미해결**

## 3. 연구 갭

**갭 A — 보정된 트리거의 부재 (CES 한계 3·5 × 개입 계열의 공통 한계).** 생성 중 개입 방법들은 전부 "불확실하면 개입"하지만, 트리거가 비보정 휴리스틱 임곗값이다. CES가 제공하는 *보정된, 비교 가능한* 점수를 개입 트리거로 쓰면 "개입률을 통계적으로 제어"할 수 있는데 아무도 안 했다.

**갭 B — 탐지 성능 ≠ 조치 효과 (평가 인프라 부재).** AUROC가 높은 탐지기가 개입 트리거로도 좋은가? 탐지→조치 전이를 측정하는 벤치마크가 없다. 모든 개입 논문이 자기 트리거+자기 정책 조합만 보고한다.

**갭 C — 고확신 할루시네이션 구간 (CES 한계 1).** 신호가 원리상 없는 구간에서 개입은 무력하거나 해롭다. "개입이 도움이 되는 불확실성 대역"의 경계를 체계적으로 그린 연구가 없다.

## 4. 제안 주제

### 🟢 주제 1 (권장 — 조건에 정확히 부합): "탐지기→개입 정책" 전이 벤치마크

**제목 초안**: 탐지가 좋다고 조치도 좋은가: 생성 중 할루시네이션 개입의 트리거-정책 분리 벤치마크
*(Does Better Detection Mean Better Mitigation? A Trigger–Policy Benchmark for In-Generation Hallucination Intervention)*

**핵심 주장 (claims)**:
1. 탐지 AUROC와 개입 후 사실성 개선은 **단조 관계가 아니다** — 트리거 품질과 정책 품질은 분리해서 평가해야 한다.
2. **보정된 트리거**(CES류)는 같은 개입 예산(개입률 x%)에서 비보정 임곗값 트리거보다 일관되게 낫다 — 모델·태스크 간 비교 가능성이 실제 이득으로 전환된다.
3. 개입의 이득은 **중간 확신 대역에 집중**된다 — 고확신 할루시네이션(갭 C)에서는 어떤 트리거·정책 조합도 무력하며, 이 대역의 크기를 처음으로 정량화한다.

**검증 설계** (API-only로 가능):
- 축 1 트리거: 고정 임곗값 엔트로피 · 길이정규화 엔트로피 · CES 재현 · 랜덤(하한)
- 축 2 정책: 고엔트로피 토큰 재샘플링(top-p 축소) · 프리픽스 잘라 재생성 · 답변 보류(abstain) · 무개입(하한)
- 모델: logprob 노출 API(예: OpenAI logprobs) + 로컬 소형 오픈 모델 2~3개 (llama.cpp/vLLM)
- 데이터: 단답 QA(TriviaQA/NQ류) + 장문(전기 생성, claim 단위 채점) — CES가 안 간 장문까지 가면 한계 5 공략 보너스
- 메트릭: 개입률 대비 사실성 개선 곡선 (intervention-budget curve), 무해성(정답을 망치는 비율)

**기여 문장 초안**: (i) 트리거×정책을 직교 분해한 첫 벤치마크, (ii) 보정 트리거의 이득 정량화, (iii) 개입 가능 대역의 경계 측정, (iv) 코드·프로토콜 공개.

**타겟 베뉴**: ACL/EMNLP/NeurIPS 계열 워크숍 (신뢰성·불확실성·사실성 주제 워크숍이 매년 다수 개최 — 마감은 본 학회 일정 확인 필요).

**리스크와 폴백**: CES 재현이 막히면(보정 데이터 구축 비용) 길이정규화 엔트로피+분위수 보정으로 대체해도 주장 1·3은 성립. 장문 채점이 비싸면 단답 QA만으로 축소.

### 🟡 주제 2 (도전): 보정된 순차 개입 — CES의 온라인 확장

생성 중 매 토큰에서 순차 가설검정(sequential test)으로 "지금까지의 엔트로피 궤적이 기준에서 이탈했는가"를 판정하고, 이탈 시점에 즉시 개입. **개입률(false-intervention rate)을 보정으로 제어**한다는 보장을 붙이면 CES의 future work(순차 구조)을 정면으로 받는 것. 이론 작업이 좀 필요해 1~2개월로는 빠듯하지만, 주제 1의 벤치마크 위에 얹으면 후속 논문으로 자연스럽다.

### 🔴 주제 3 (프런티어, 이번 조건에는 비권장): 고확신 할루시네이션의 외부 신호 결합

엔트로피 신호가 0인 구간(갭 C)은 모델 내부 신호로는 원리상 불가능 → retrieval 일치도 등 외부 신호와의 결합이 필요. 학습·인프라 요구가 커서 6개월+ 과제.
