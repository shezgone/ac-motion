# ac-motion 데모 영상 시나리오 (3분, 한국어)

졸업과제 발표용 / 시연 영상용. 우측 상단 `▶ demo` 버튼이 자동 재생하는 캡션·필터·카메라 시퀀스(약 35초)와 사용자가 직접 보여줘야 하는 손 제스처 부분(약 90초)을 합치면 ~2분 30초.

## 0. 사전 준비

- macOS 표준 단축키: **⌘+Shift+5** → 화면 + 웹캠 PIP 동시 녹화 가능 (옵션 → 카메라 켜기)
- Chrome 창을 1280×800 정도로 고정 (가로/세로 비율 안정)
- 카메라 권한 미리 허용
- dev 서버 띄운 상태에서 `http://127.0.0.1:5173/` 접속 후 안정화 5초 대기

## 녹화 명령 (macOS, 단일 mp4 출력)

### QuickTime
1. **⌘+Shift+5**
2. 옵션 → 카메라(웹캠) 선택, 마이크 선택
3. "전체 화면 기록" 또는 "선택한 영역 기록"
4. 정지하면 ~/Desktop/screenrecord.mov 저장

### ffmpeg로 mov → mp4 + 가로 크롭
```bash
ffmpeg -i ~/Desktop/screenrecord.mov \
  -vf "crop=1280:720:0:0,scale=1920:1080" \
  -c:v libx264 -preset slow -crf 20 \
  -c:a aac -b:a 192k \
  ac-motion-demo.mp4
```

### 자막 입히기 (선택)
별도 SRT 파일(`ac-motion-demo.srt`) 만든 뒤:
```bash
ffmpeg -i ac-motion-demo.mp4 -vf subtitles=ac-motion-demo.srt out.mp4
```

## 트러블슈팅

- **손 인식이 끊김** → 조명 강화, 손 카메라 거리 30~50cm 유지
- **Demo Mode가 노드 못 찾음** → 시작 전 사이드바 reset 누르기 (필터가 너무 좁으면 ICML/CVPR이 화면에 없을 수 있음)
- **회전이 너무 빠름** → `Graph3D.tsx`의 `ORBIT_SPEED` 상수 4 → 2로 낮춤
- **빌드 후 흰 화면** → Chrome devtools 콘솔 확인. CSP 또는 favicon 차단 가능성
